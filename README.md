# Khuzaima Sohail — Portfolio

A complete responsive React + Vite portfolio website.

## Included

- Responsive desktop/tablet/mobile layout
- Dark/light theme
- Animated smooth scrolling
- About, Skills, Experience, Projects and Contact sections
- LinkedIn and GitHub links
- InnoPlanner project
- Profile photo in `public/profile.png.jpeg`
- Firebase Hosting-ready production build

## Run in VS Code

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Open the terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite.

## Production build

```bash
npm run build
```

The production files will be inside `dist/`.

## Firebase Hosting

Install Firebase CLI:

```bash
npm install -g firebase-tools
```

Login:

```bash
firebase login
```

Initialize Hosting in this project:

```bash
firebase init hosting
```

Use `dist` as the public directory and configure it as a single-page app.

Then:

```bash
npm run build
firebase deploy
```
